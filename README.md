# AI Job Analysis Project

## Overview
This project analyzes AI job market data to understand trends like job demand, salary distribution, and experience levels. It helps in exploring how the AI industry is growing.

---

## Objectives
- Identify the most in-demand AI job roles  
- Analyze salary distribution  
- Understand the impact of experience on salary  
- Explore job opportunities across different locations  

---

## Dataset
The dataset contains the following columns:
- Job Title  
- Salary  
- Experience Level  
- Location  
- Company  

> Note: Missing values were handled during data cleaning.

---

## Tools & Technologies
- Python  
- Pandas  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

## Project Workflow
1. Data Cleaning (handling null values, formatting data)  
2. Data Analysis (grouping and aggregation)  
3. Data Visualization (charts and graphs)  
4. Insight Generation  

---

## Key Insights
- Some job roles are more in demand than others  
- Salary increases with experience  
- Certain locations have more job opportunities  

---

## Conclusion
This project provides useful insights into the AI job market and is helpful for beginners learning data analysis.
